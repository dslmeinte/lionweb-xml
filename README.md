# lionweb-xml

* The `build` package generates various artifacts, also in other packages.
* The `lionweb-ecore` package contains an implementation (based on `@lionweb/class-core`) of the EMF Ecore language.
* The `lionweb-xml` package contains:
  * An *extractor* that extract a LionWeb language from an XML file.
  * An *XML reader* that reads an XML file as an instance of a conformant LionWeb language.
